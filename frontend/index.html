Mission brief

Recover the root signature

Every solved node unlocks part of the narrative and awards points. Hints stay optional, answers are checked in the browser only, and the final flag requires the exact format BRANCHES{NEON_ROOT}.

  • Each node accepts a short token.
  • Empty submissions and malformed formats produce distinct feedback.
  • The final terminal unlocks after all four nodes are solved.

Browser-side state only. No network calls. No persistence beyond localStorage.
