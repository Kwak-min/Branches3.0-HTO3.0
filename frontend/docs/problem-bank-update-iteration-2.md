# Problem Bank 업데이트 2차 검토

## 이번에 추가한 것

- 1차 검토에서 부족하다고 판단한 챕터별 학습 상태 표시를 보강했다.
- 전체 문제 수, 맞은 문제, 오답 기록, 보완 필요 챕터를 한눈에 보는 상태 요약 영역을 추가했다.
- 오답이 많은 챕터와 진행률이 낮은 챕터를 기준으로 보완 필요 챕터가 자동 표시되도록 했다.
- AI 코치 영역 아래에 추천 문제와 학습 상태가 이어지도록 배치해 문제풀이 플랫폼 느낌을 강화했다.

## 다시 보고 부족해 보이는 부분

- 추천 문제는 화면에 보이지만, 사용자가 왜 이 문제를 받았는지에 대한 기준 설명이 더 명확해야 한다.
- 정답 제출 이후 다음 행동이 자동으로 안내되지 않아 백준식 연속 풀이 흐름이 약하다.
- 업데이트 내역이 문서별로 흩어져 있으므로 최종 문서에서 통합 변경 사항과 앞으로 할 일을 정리해야 한다.

## 다음에 해야 할 것

- 3차 업데이트에서는 AI 추천 기준과 사용 흐름을 문서와 UI 문구에 더 명확히 남긴다.
- 최종 MD에 3회 반복 결과, 추가된 파일, 다음 개선 후보를 정리한다.
- 빌드와 타입 진단으로 실제 동작 가능성을 확인한다.
