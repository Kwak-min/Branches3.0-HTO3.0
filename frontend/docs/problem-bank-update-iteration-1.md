# Problem Bank 업데이트 1차 검토

## 이번에 추가한 것

- 기존 문제은행 데이터를 7개 보안 챕터 구조로 재편했다.
- 챕터는 웹 기초 정찰, 인증과 세션, 인젝션 공격, 암호와 인코딩, 포렌식과 로그, 네트워크 분석, 리눅스 권한 상승으로 구성했다.
- 각 챕터에 2문제씩 총 14개 문제를 배치했다.
- 난이도는 Bronze, Silver, Gold, Platinum으로 유지해 백준식 등급 감각을 살렸다.
- 사용자가 선택한 실력 단계에 맞춰 미해결 문제를 추천하는 AI 난이도 코치 영역을 추가했다.

## 부족해 보이는 부분

- 추천 기준은 난이도와 정답률 중심이라, 챕터별 약점 분석이 아직 약하다.
- 화면 상단에 챕터 흐름은 생겼지만, 문제풀이 플랫폼처럼 상태 요약이 더 명확해야 한다.
- 문서상으로는 업데이트 방향을 남겼지만, 다음 개발자가 바로 확인할 체크리스트가 더 필요하다.

## 다음에 해야 할 것

- 챕터별 진행률과 약점 표시를 더 눈에 띄게 만든다.
- 오답 누적 시 복습 문제를 우선 추천한다는 UX를 강화한다.
- 2차 업데이트에서는 문제풀이 현황/AI 추천 근거/챕터 카드 시각화를 보완한다.
