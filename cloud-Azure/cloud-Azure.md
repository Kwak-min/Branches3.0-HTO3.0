## 모듈별 핵심 정의 및 요약

### 1. 클라우드 개념 (Cloud Concepts)
* **클라우드 컴퓨팅**: 인터넷을 통해 컴퓨팅 서비스(서버, 스토리지 등)를 제공하는 것.
* **클라우드 모델**: 퍼블릭(불특정 다수), 프라이빗(단일 고객 전용), 하이브리드(퍼블릭+프라이빗 조합).
* **공유 책임 모델**: IaaS(고객 책임 가장 큼), PaaS(개발자는 코드에만 집중), SaaS(완성된 소프트웨어 이용).

### 2. Azure 아키텍처 및 서비스 (Azure Architecture)
* **지역 (Regions)**: 전 세계에 분산된 데이터 센터의 지리적 묶음.
* **가용성 영역 (Availability Zones)**: 재해 복구를 위해 물리적으로 분리된 데이터 센터 환경.
* **리소스 그룹 (Resource Groups)**: Azure 리소스들을 논리적으로 묶어 관리하는 폴더 역할.

### 3. Azure 관리 및 거버넌스 (Management and Governance)
* **비용 관리 (Azure Cost Management)**: 클라우드 요금을 모니터링하고 예측하는 도구.
* **Azure Policy**: 회사의 기준이나 법적 요구사항을 준수하는지 강제하는 규칙 체계.
* **Azure 태그 (Tags)**: 리소스에 이름/값 쌍을 붙여 부서별, 프로젝트별로 자원을 분류하는 기능.
