# HTO 3.0 문제 피드백 AI 구축 방안

## 개요

Hack This Out 3.0은 사용자가 보안 문제를 풀이하며 학습할 수 있는 플랫폼이다.

현재 사용자는 문제를 해결한 후 정답 또는 오답 여부만 확인할 수 있다.

하지만 문제를 해결하더라도 취약점 원리나 공격 과정, 방어 방법을 이해하기 어려운 경우가 많다.

이를 해결하기 위해 Claude API를 활용한 문제 피드백 AI 기능을 구축하고자 한다.

---

## 목표

문제 제출 후 AI가 사용자에게 학습용 피드백을 제공한다.

제공 내용

* 취약점 설명
* 공격 원리 설명
* 방어 방법 설명
* 추가 학습 방향 제시

---

## 구현 우선순위

### 1단계 (우선 구현)

정답 제출 시 AI 해설 제공

사용자가 문제를 해결하면 Claude API를 통해 해당 취약점에 대한 설명을 생성한다.

예시

* SQL Injection 원리
* 공격 과정
* 방어 방법

---

### 2단계

오답 제출 시 AI 힌트 제공

정답을 직접 알려주지 않고 문제 해결 방향만 제시한다.

---

### 3단계

사용자 수준별 맞춤 피드백 제공

초급자와 고급자에게 다른 수준의 설명을 제공한다.

---

## 예상 시스템 구조

사용자

↓

문제 제출

↓

Backend API

↓

Claude API

↓

피드백 생성

↓

Frontend 출력

---

## 기대 효과

* 초보자의 학습 효율 향상
* 문제 해설 자동화
* 운영진 부담 감소
* 사용자 맞춤형 학습 지원

---

## 결론

현재 Hack This Out 3.0 구조에서는 문제 생성 AI보다 문제 피드백 AI가 구현 난이도가 낮고 현실성이 높다.

따라서 초기 버전에서는 정답 제출 후 AI 해설 기능을 우선 구현하는 방향이 적절하다고 판단된다.
